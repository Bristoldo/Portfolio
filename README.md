# Developer Portfolio

A responsive, dark-themed portfolio website built with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a modern browser. An internet connection is used only for the optional Google Fonts import; system fallbacks are included.

## Before publishing
1. Search `index.html` and `script.js` for `YOUR_` placeholders.
2. Update email, LinkedIn, GitHub, and project repository URLs.
3. Review project descriptions and ensure all claims accurately reflect your contribution.
4. Replace illustrative project artwork with authorized screenshots or demos if available.
5. Remove or adapt any section that does not reflect your current availability or services.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example `portfolio`).
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Open repository **Settings → Pages**.
4. Choose deployment from the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

The site is static; no backend or database is required.
